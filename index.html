⚠️ 若所选服务商不支持图片（如 DeepSeek 的 API 仅支持文字），「AI 看图识字」会自动回退到本地 OCR（准确率较低）。想用 AI 看图，把服务商改成支持视觉的即可。

使用说明

1. 准备 API Key

首次使用需要配置大模型 API Key（保存在你的浏览器本地，不会上传到任何服务器）。

2. 选择输入方式

支持拍照 / 上传图片 / 直接输入英文文本。图片会先在浏览器中 OCR 识别为文字。

3. 等待 AI 批改

大约 5-15 秒。批改完成后会在原文上用红圈标出错误位置，右侧显示中文批注。

4. 分享

可以复制链接分享给老师同学，或导出为 PDF 存档。
